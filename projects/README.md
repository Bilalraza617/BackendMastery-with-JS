# Projects

This folder contains mini JavaScript practice projects for backend learners.
Each project is built with plain JavaScript and includes clear README instructions.

## Available projects

- `simple-grade-calculator`
  - A complete student grade report system.
  - Uses arrays, objects, loops, conditions, functions, and basic program structure.
  - No Promises used.

## Run a project

```bash
node <project-name>/index.js
```

Example:

```bash
node simple-grade-calculator/index.js
```
