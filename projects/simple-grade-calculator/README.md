# Simple Grade Calculator

A detailed grade-report project built with plain JavaScript.
This project shows how to store student data, calculate averages, assign grades, and print a full class report.

## What you will learn

- organizing data with arrays and objects
- writing reusable functions
- using loops and conditions
- formatting output with template strings
- calculating summary statistics
- no Promises used

## Files

- `index.js` — main code for data processing and report printing

## How it works

1. Student data is stored in an array of objects.
2. Each student has scores for multiple subjects.
3. The program calculates each student's average.
4. A letter grade is assigned based on the average.
5. The program prints a report for every student.
6. It also prints class summary statistics.

## Run

```bash
node index.js
```
