# Simple Grade Calculator

A detailed grade-report project built with plain JavaScript and browser UI.
This project lets you add students from a web form, then generate a full report on the page.

## What you will learn

- working with HTML forms
- reading user input from the UI
- using arrays and objects
- writing reusable functions
- using loops and conditions
- updating page content with JavaScript
- no Promises used

## Files

- `index.html` — user interface and form layout
- `style.css` — page style and layout
- `index.js` — logic for student report generation

## How it works

1. Use the form to enter student name, roll, section, and three scores.
2. Click Add Student to store the data.
3. Click Generate Report to calculate averages and grades.
4. The report appears below with class summary information.

## Run

Open `index.html` in your browser.

## Example UI flow

- add multiple students using the form
- see the student list update immediately
- press Generate Report
- view each student report, class average, and grade counts
